### 🚀 Featured Active Work (Private Repositories)

#### 1. Multi-Tenant AI Knowledge Platform (`Python · FastAPI · ChromaDB · Ollama · BM25`)
An end-to-end, production-hardened Retrieval-Augmented Generation (RAG) backend built for accuracy, multi-tenant security, and low latency:
* **Hybrid Retrieval & Reranking:** Combines BM25 lexical search and dense vector similarity via **Reciprocal Rank Fusion (RRF)**, followed by LLM-based relevance reranking.
* **Grounded Generation:** Enforces evidence verification, automated citation validation, and **safe abstention** when context falls below confidence thresholds.
* **Enterprise Security:** Implements API-key auth, strict **tenant isolation**, document-level RBAC, and **prompt-injection mitigation** for untrusted documents.
* **Observability & Evaluation:** Features stage-level latency tracing, request deadlines, retry/timeout handling, and an automated **Pytest benchmark harness** tracking throughput, concurrency, and citation validity.
